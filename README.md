# 📊 E-commerce Client Spending Prediction – Linear Regression Project

This project applies **Linear Regression** to analyze and predict customer spending behavior on an e-commerce platform. The main goal is to help the company decide whether to focus their efforts on enhancing the **mobile app** or the **website experience**.

## 📁 Dataset

The dataset used in this project is available on [Kaggle](https://www.kaggle.com/iyadavvaibhav/ecommerce-customer-device-usage/notebooks). It contains data on customer behavior, including:

- **Avg. Session Length**: Average duration of in-store style advice sessions.
- **Time on App**: Average time spent using the mobile app (in minutes).
- **Time on Website**: Average time spent on the website (in minutes).
- **Length of Membership**: Number of years the customer has been a member.
- **Yearly Amount Spent**: Target variable representing the yearly amount a customer spends on the platform.

## 🧠 Objective

To build a **Linear Regression model** that:
- Understands the relationship between app/website usage and customer spending.
- Helps the business decide where to focus—improving the app or the website.

## 📌 Project Steps

1. **Data Exploration and Visualization**  
   - Understand data structure and relationships through plots and statistics.

2. **Data Preprocessing**  
   - Clean and prepare the data for modeling.

3. **Model Training**  
   - Apply Linear Regression to build a predictive model.

4. **Model Evaluation**  
   - Evaluate model performance using error metrics and visualizations.

5. **Insights & Recommendation**  
   - Use findings to provide a data-driven recommendation on whether the app or website needs more attention.

## 🧰 Tools and Technologies

- Python  
- Jupyter Notebook  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- Scikit-learn  

## 🚀 Outcome

A clear, data-backed recommendation on how customer behavior correlates with spending, guiding product and UX development for improved customer retention and profitability.
